# v1.0.0-beta2

## 日本語

- 通知文とMinecraftの進捗名を、日本語・英語と第二言語範囲を合わせた22言語に対応しました。
- `MODS_DIR` のMOD JARから翻訳リソースを抽出し、進捗・実績・死亡メッセージの翻訳に利用します。内容のハッシュに基づくキャッシュを保存し、翻訳を特定できない場合は元の文を保持します。
- OpenMapMC Deltaの共有ウェイポイントの作成・編集・削除を通知します。操作した本人の名義で、編集後または削除直前の地点情報を表示します。対応する構造化ログを出力するサーバーMODが必要です。
- 設定を `send-minecraft-notifications.toml` に移行しました。旧 `.env` が見つかると元ファイルを残して変換します。旧Python版の設定フォルダーも検出できます。
- 公開チャットの原文にオフラインの日本語変換を併記できるようになりました。この機能は既定で無効です。
- Windowsの公開EXE名にアプリ名・リリースバージョン・対象OSを含め、ダウンロード手順をリリースごとに生成します。

Windows x64 / Linux x64の実行ファイル、ZIP、SHA-256チェックサムを配布します。更新前に設定を保管し、更新後は `--check-config` で検査してから通知プログラムを再起動してください。新機能の設定例は同梱のREADMEと `send-minecraft-notifications.example.toml` にあります。

## English

- Added 22 notification languages and translated Minecraft advancement names.
- Extract MOD translation resources from JARs in `MODS_DIR` for advancement, achievement and death notifications. Resources are cached by content hash; messages with unresolved translations retain their original text.
- Notify OpenMapMC Delta shared waypoint creation, editing and deletion using the actual actor's identity and the saved updated or last stored location. The server MOD must emit the corresponding structured events.
- Moved settings to `send-minecraft-notifications.toml`. Legacy `.env` settings are converted while preserving the original file, including discovery of neighboring legacy Python installations.
- Added optional offline Japanese conversion alongside original public chat messages, disabled by default.
- Public Windows executable names now include the application, release version and target platform. Installation commands are generated for each release.

Windows x64 and Linux x64 binaries, ZIP archives and SHA-256 checksums are provided. Preserve your configuration before updating, run `--check-config`, and restart the notifier. See the bundled README and `send-minecraft-notifications.example.toml` for the new settings.
